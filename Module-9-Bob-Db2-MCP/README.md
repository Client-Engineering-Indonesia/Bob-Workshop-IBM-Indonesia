# Module 9 — IBM Bob × IBM Db2 Connection via MCP

This module demonstrates how to connect **IBM Bob** (AI Software Engineer) to **IBM Db2** using a custom **Model Context Protocol (MCP)** server. Once connected, Bob can query, manage, and monitor Db2 databases directly from the chat interface — no separate SQL client needed.

---

## Before You Start — What Bob Can and Cannot Do Automatically

Understanding this upfront will save you time. Bob can automate most of the setup — but a few steps require your action because they involve Windows installers or Bob's own UI.

| | Task | Who does it |
|---|---|---|
| ✅ | Create all project files (`package.json`, `tsconfig.json`, `src/index.ts`) | **Bob** |
| ✅ | Run `npm install` and `npm run build` | **Bob** |
| ✅ | Write `mcp.json` with your credentials | **Bob** |
| ✅ | Fix build errors | **Bob** |
| ⚠️ | Install Node.js — requires clicking through a Windows installer | **You** |
| ⚠️ | Install IBM Db2 ODBC Driver — requires Windows installer + admin approval | **You** |
| ⚠️ | Set `IBM_DB_HOME` environment variable — requires Windows System Settings | **You** |
| ❌ | Click **Restart** in Bob's MCP panel — Bob cannot click its own UI | **You (always)** |

> **Estimated time:**
> - First-time setup: **~25–30 minutes** (mostly waiting for installers)
> - Reconnecting to a new environment: **~2 minutes** (update IP → restart MCP panel)
