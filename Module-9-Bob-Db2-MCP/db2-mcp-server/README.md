# db2-mcp-server

This is the MCP server that connects **IBM Bob** to **IBM Db2**. It is a Node.js/TypeScript application that Bob runs automatically in the background.

---

## What's in this folder

| Item | What it is |
|---|---|
| `src/index.ts` | Full MCP server source code (TypeScript) |
| `package.json` | Project definition + all dependencies |
| `tsconfig.json` | TypeScript compiler configuration |
| `node_modules/` | Installed packages — generated by `npm install` |
| `build/index.js` | Compiled output — generated by `npm run build` ← Bob runs this |

> `node_modules/` and `build/` are not included in this repository. You generate them on your machine by following the steps below.

---

## Setup (3 steps)

### Step 1 — Install dependencies
Open a terminal inside this folder and run:
```bash
npm install
```

### Step 2 — Build the server
```bash
npm run build
```
This compiles `src/index.ts` → `build/index.js`. No output = success.

### Step 3 — Configure credentials
Copy `mcp.json.example` from the module root to:
```
C:\Users\<YourUsername>\.bob\settings\mcp.json
```
Open it and fill in your Db2 credentials (`DB2_HOST`, `DB2_PASSWORD`).
